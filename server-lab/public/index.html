Принципы доверия

01Личная ответственность

У каждой записи есть реальный автор и принадлежащий ему мир.

02Никаких фальшивых счётчиков

Публикации берутся из SQLite лаборатории. Черновики видит только автор.

03Модерация

Жалобы доступны независимой роли модератора; чужие записи нельзя редактировать.

Жалобы на проверку

Лаборатория не имеет подтверждения почты, восстановления аккаунта, долговременной защиты от атак и production-инфраструктуры. Для публичного запуска нужен отдельный аудит.
