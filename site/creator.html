Полное резервное копирование работает только в этом браузере. Импорт ограничен 2 МБ и максимум 8 проектами.

PRIVATE / AES-256-GCM · R12

ЗАЩИЩЁННЫЙ АРХИВ

◇ PBKDF2 · 600K

Скачай резервную копию с паролем. Текст историй внутри файла шифруется прямо в браузере. Для восстановления нужен тот же пароль.

Используй длинную уникальную парольную фразу — минимум 12 символов. Лучше несколько случайных слов. Мы не сохраняем пароль.

◇

Если забудешь пароль, файл восстановить невозможно. Сам локальный архив в браузере НЕ зашифрован. Старый экспорт JSON без пароля по-прежнему доступен выше.
