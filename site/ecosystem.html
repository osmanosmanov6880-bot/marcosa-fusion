03 / ПУБЛИЧНЫЕ ИСХОДНИКИ

Атлас наших проектов

Записи основаны на метаданных GitHub. Для закрытых репозиториев исходники и адреса намеренно не раскрываются.

Загрузка реестра…

«Исходники доступны» ≠ «приложение развёрнуто». Отдельные сервисы требуют собственной инфраструктуры, проверки зависимостей, секретов и договорённостей о маршрутах. Ни один внешний проект не помечен работающим на marcosa.club без независимого HTTPS readback.

04 / RELEASE BOUNDARY

Сначала доказательства. Затем публикация.

Главный marcosa.club и его legacy-приложение, аккаунты и Supabase не затрагиваются этой страницей. Новый код попадает только в публичный preview и изолированный STAGING после прохождения GitHub Actions. Подмена основного production запрещена без проверенного восстановления данных, legacy-совместимости и отдельного человеческого GO.
