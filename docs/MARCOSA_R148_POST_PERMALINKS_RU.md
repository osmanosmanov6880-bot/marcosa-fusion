# MARCOSA R148 — постоянные ссылки на публикации

## Пользовательский путь

- Карточки опубликованных постов содержат постоянную ссылку вида `/w/<slug>#post-<id>`.
- При открытии адреса приложение загружает мир, получает конкретный пост и переносит фокус к публикации. Ссылка работает и для старых публикаций за пределами первой страницы ленты.
- Профиль автора, поиск, сохранённые записи и события реакций ведут на тот же адрес.

## Серверная проверка доступа

`GET /api/worlds/:slug/posts/:id` возвращает только опубликованную запись из указанного мира. Черновики, скрытые посты, закрытые миры, недоступные приватные профили и заблокированные связи отвечают `404`, без раскрытия существования объекта.

## Проверка

`server-lab/test/r148.post_permalinks.test.mjs` проверяет публичный адрес, неверное соответствие поста миру, черновик, закрытый профиль, одобренного подписчика и блокировку. MARCOSA остаётся локальной SQLite лабораторией; публикация домена и production не выполнялись.
