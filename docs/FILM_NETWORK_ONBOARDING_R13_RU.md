# MARCOSA R13 — первый реальный шаг к интеграции 43 сайтов кино

**Состояние:** добавлен рабочий локальный инструмент аудита `film-network.html`, готовый к публикации через GitHub Pages после CI. Он **не** получает данные с чужих сайтов, не изменяет `marcosa.club`, не публикует код на доменах и не создаёт мнимый трафик или рекламу.

## Исходный факт

В `inventory/film-sites.csv` находятся 43 пустых слота FILM-01—FILM-43, без подтверждённых URL. Это не 43 проверенных работающих фильма. Поэтому приоритетом R13 стал инструмент безопасного импорта списка владельца и отбора трёх площадок в технический пилот.

## Что реально реализовано

- Импорт CSV с полями `asset_id,verified_domain,project_name`, в том числе из существующего шаблона. Каждый настоящий сайт представлен уникальным доменом HTTPS и идентификатором FILM-01—FILM-43.
- Лимит 43 кандидатов, ограничение входного CSV 256 КиБ, запрет опасных схем, локальных IP, подстановки пути и query, дубликатов доменов/слотов и неверных ID.
- Восемь самостоятельных **авторских самопроверок**: управление доменом, права на контент, работоспособность интерактивной истории, мобильная навигация, место перехода после финала, тематическая связь с MARCOSA, доступ к исходникам и проверка скорости. По умолчанию все пункты выключены; никакая отметка не является независимым доказательством.
- Первая тройка кандидатов строится **только после шести обязательных отметок**. Дополнительные две позволяют упорядочить список. Цифра «8/8» означает только количество заявлений владельца, а не фактическую готовность, скорость или рейтинг бизнеса.
- JSON-пакет `marcosa-film-pilot-evidence/v1` с исходными доменами, неизменным статусом `externally_verified:false`, `not_published`, списком пробелов и кандидатами на ручную проверку.
- Отдельный HTML-сниппет добровольного перехода после финала — после авторских подтверждений домена, прав и наличия места. Содержимое безопасно экранируется; вставляется вручную после согласования с владельцем. Шаблон не публикует и не выполняет отслеживание.
- RU/EN/中文, доступные кнопки и мобильная адаптация. Все данные остаются в **текущей вкладке**, файлы сохраняются только по клику. Импорт не вызывает обход/сканирование сетевых URL и не устанавливает cookies.

## Чего пока нет

Не обнаружены в репозитории проверенные 43 адреса, права на контент, исходники всех фильмов, реальные аналитические данные по зрителям и подтверждённые конверсии. R13 не подтверждает эти факты. Также нет server-side аналитики, cross-domain identity, live-переходов из реальных фильмов или рекламных договоров.

## Обязательная приёмка

1. Node: `tests/film_network.test.cjs` — пустые слоты, валидация доменов, права, shortlist, XSS.
2. Python: `tests/test_public_release.py` — статическая allowlist-сборка теперь из 18 публичных файлов.
3. GitHub Actions: общие Node/Python-тесты + Chromium QA прежнего каталога/игр, без регрессий.
4. После релиза: с настоящим перечнем доменов владельца подготовить три кандидата; вручную открыть каждую историю на компьютере и телефоне, проверить исходники, юридическое основание и время загрузки; только потом встраивать CTA.

## Приоритет продуктовой экономики

Цель пилота — проверить, что люди добровольно переходят из **готовой истории** к подходящей странице MARCOSA, без навязчивой рекламы. Дальнейшие продуктовые метрики: число просмотров финала, число добровольных кликов CTA, доля полезных последующих действий и повторные визиты — **только при законно настроенной измерительной системе и проверенных источниках**, которой R13 пока не добавляет. Не считать скачивание планов или импорт 43 строк доказательством спроса.
