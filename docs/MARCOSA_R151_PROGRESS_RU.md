# MARCOSA R151 — приватное чтение и лабораторная приёмка

База: PR #168, ветка `feature/marcosa-r150-growth-economics`. Изменения сделаны в **изолированной лаборатории** Node/SQLite, без подключения денег и без деплоя.

## Пять функциональных блоков

1. **Каталог**. Поиск с устойчивой пагинацией по ID; максимум 20 сезонов на страницу, `nextCursor` в API и ссылка на следующую страницу. Проверка видимости и блокировок выполняется для каждой страницы.
2. **Продолжение чтения**. `GET /api/me/series-continue` возвращает первый доступный опубликованный эпизод, который участник ещё **добровольно не отметил**. Страница каталога показывает приватные ссылки; прочтение **не определяется слежением за страницами**.
3. **Управление напоминаниями**. `DELETE /api/me/series-reminders/:episodeId` скрывает только собственное напоминание, допускает повтор и остаётся доступным при аварийной остановке публикаций. У других участников записи не изменяются; Origin проверяется до изменений.
4. **Финансовая чувствительность**. `tools/finance/analysis.mjs` сравнивает базу и пять стресс-сценариев. `breakEvenMau` — условная линейная точка безубыточности при неизменных допущениях, `null` означает недостижимость при масштабировании с текущей маржинальностью. 9 исходных профилей × 6 вариантов. Никаких настоящих платёжных реквизитов.
5. **Браузерная приёмка**. Отдельный workflow запускает Chromium через Playwright, проверяет ошибки JS, горизонтальную прокрутку и делает PNG для экранов 1440, 390, 360. При ошибке браузера прогон должен оставаться красным, а не имитировать успех.

## Команды проверки

```sh
node --test server-lab/test/*.test.mjs
node --test tools/finance/model.test.mjs tools/finance/analysis.test.mjs
node tools/finance/analyze.mjs > /tmp/marcosa-r151-stress.json
npm install --prefix tools/browser --ignore-scripts
npx --prefix tools/browser playwright install chromium
node tools/browser/smoke.mjs
```

**Ограничения:** прототип без реального выпуска денег/выплат. Снимки — только доказательство от GitHub Actions при успешном запуске. Аудит инфраструктуры, продакшн Auth/PostgreSQL, GDPR и браузерная проверка авторского пути остаются отдельными воротами. Коммерческий production запрещён до независимой приёмки.
