# MARCOSA R77 — живой двуязычный интерфейс пользовательских действий

**Сфера:** действующее локальное Node 22/SQLite приложение, а не облачный production. Продолжение R71 после статической RU/EN оболочки.

## Реальная продуктовая функциональность

1. Добавлены **42 системные RU/EN записи** для динамически создаваемых элементов: подписаться/отписаться, заблокировать участника, обсуждение, сохранить/удалить публикацию, пожаловаться, отправить ответ, открыть сайт, скрыть нарушающий материал, отменить рекламную заявку, пустые состояния каталога, ленты, комментариев, жалоб, модерации и тестовых рекламных предложений.
2. `systemNode(tag,key,fallback,cssClass)` создаёт системную кнопку или описание через `textContent`, закрепляет идентификатор перевода `data-i18n-dynamic` и больше не меняет его смысл. Смена языка переводит такие элементы **без перезагрузки** или повторного запроса к серверу.
3. Частные системные элементы со значениями, которые менять нельзя (имя владельца в кнопке блокировки, число комментариев в заголовке обсуждения), собираются как `localized prefix + unchanged suffix`. Смена языка сохраняет точное имя или счётчик. Текст чужих сообщений, карточек World и рекламодателей остаётся неизменным.
4. У редактируемого комментария локализуется только `placeholder`. Существующее значение `textarea.value` никогда не перезаписывается, поэтому пользователь не теряет набранный текст, переключая язык. Кнопка `Сохранить`/ `Сохранено ✓` сохраняет верную локаль даже сразу после действия.
5. Нет сторонних API перевода, `innerHTML`, `MutationObserver` или автоматического распознавания и перевода произвольного UGC.

## Исполняемая приёмка

- `server-lab/test/r77.dynamic_locale_keys.test.mjs` гарантирует, что все 42 ключа существуют в словаре и реально используются, не дублируют русские исходники, не опираются на небезопасную автоматическую переводческую логику и не трогают исходный текст публикаций/комментариев.
- Настоящий `server-lab/test/r71.bilingual_browser_cdp.mjs` на 1440, 390 и 360 px теперь дополнительно проверяет двустороннее RU/EN обновление обсуждения и статуса отсутствия пилотной рекламы, одновременно сравнивая неизменность опубликованного текста пользователя.
- Новый тест включён в обязательную `MARCOSA | real social server + World/Ads lab` GitHub Actions наряду со всем прежним реальным HTTP/Chromium набором. Merge разрешается **только после успешного CI точного SHA**.

## Открытые границы

R77 охватывает главные динамические кнопки и пустые состояния, **не все возможные статусы, ошибки API, юридические документы, пользовательские модальные диалоги и системные письма**. Их переводы и независимая проверка носителями языка остаются обязательными до международного выпуска. Постоянные ссылки Worlds по-прежнему `noindex` в локальном сервере; включение публичного SEO требует реального HTTPS STAGING, Auth/Storage и независимой юридической приёмки.
