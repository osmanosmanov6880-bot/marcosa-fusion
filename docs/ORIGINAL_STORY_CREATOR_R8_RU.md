# MARCOSA R8 — Original Story Creator Engine

**Выпуск:** 23 октября 2026. **Тип:** публичный статический Network OS. **Доставка:** GitHub Pages после CI. Не production marcosa.club, не сервис для публикации историй на реальных доменах.

## 1. Что реально работает

На странице creator.html появился **конструктор собственных интерактивных сюжетов**:

1. Автор редактирует название, краткую идею, первую сцену, вопрос и 2 решения.
2. Для **каждого** первого решения создаёт самостоятельную вторую сцену с 2 вариантами.
3. Для четырёх маршрутов A→A, A→B, B→A, B→B пишет **четыре собственных финала**.
4. Нажимает «Обновить предпросмотр» и **проходит свой сюжет как посетитель** (выбор, возврат, перезапуск, финал).
5. Подтверждает права и прозрачную маркировку потенциального спонсорства, затем скачивает переносимый JSON-черновик.
6. Может локально импортировать JSON R8 для повторной редакции. После импорта **обязан повторно подтвердить права**.

Контент в редакторе изначально заполнен образцом «Город последнего сигнала» — **явно вымышленной стартовой историей**. Смена RU / EN / 中文 меняет **язык интерфейса**, но не переводит автоматически авторский текст.

## 2. Проверяемый контракт данных

**Схема:** marcosa-original-story/v1

- title, tagline, language;
- opening: сцена, вопрос, два варианта;
- branches: две независимые вторые сцены, каждая с двумя вариантами;
- endings: четыре независимых финала с названием и текстом;
- status: draft_only, publication_state: not_published;
- rights_self_attested, sponsorship_disclosure_committed: только заявления автора;
- rights_independently_verified: false, manual_approval: false, tracking: false, payments: false;
- review_gates: проверки прав, спонсорства, редактуры, доступности, безопасности, ручного утверждения.

Список свойств **закрытый**: неизвестные поля, вложенные лишние свойства, неверные размеры массивов, некорректные типы и неразрешённые статусы отклоняются. **Нельзя импортом превратить черновик в «опубликованную» историю.** 22 авторских текстовых поля имеют ограничения длины; строки не исполняются как HTML и вставляются в интерфейс только через textContent.

Файл JSON экспортируется локально из браузера. Максимальный размер импорта — 128 КиБ. Нет сохранения черновика на сервере, профиля пользователя, записи в localStorage, cookies или аналитики. При закрытии вкладки незагруженные изменения пропадут: экспорт — способ сохранить рукопись.

## 3. UX и визуальная система

Новая автономная страница: глубокий тёмно-синий фон, небесные частицы, красные акценты, золотые края, адаптивный редактор слева и интерактивный плеер справа. До 870 px плеер расположен **над** редактором, чтобы сразу видеть результат.

- Семантические подписи, управляемые клавиатурой формы, раскрывающиеся секции.
- Голосовой статус aria-live для ошибок/результатов; progressbar для маршрута.
- Фокус поля с ошибкой, раскрытие соответствующей секции.
- Поддержка prefers-reduced-motion.
- Не нужен backend или доступ к Contabo.

## 4. Проверка

- Node: tests/creator.test.cjs — четыре маршрута, строгие статусы, поля, импорт/экспорт, права, локализация.
- Chromium: tools/r5_browser_smoke.py — desktop и mobile; новый заголовок, финал B→A, возврат, язык, защита экспорта.
- Визуальная проверка: tools/r5_capture_preview.py — добавлены скриншоты Creator Engine.
- Статическая сборка: tools/build_webroot.py — allowlist из **11** публичных файлов с SHA-256 manifest.
- GitHub Actions: проверки новых файлов и Node-тестов в public Pages и staging build.

## 5. Реальные границы выпуска и следующий этап

R8 **не создаёт пользователей, каталоги зрительских историй, публичную публикацию, рекламу или доходы**. Не изменяет production MARCOSA, платёжные системы, Contabo или действующие проекты.

**Для настоящей коммерческой платформы позднее потребуются:** хранение проектов в БД, аккаунты и права ролей, ревизии, ручная модерация, владение доменами, персональные данные, договоры, контент-пайплайн, реальные пользовательские тесты. Эти возможности не следует выдавать за уже существующие.
