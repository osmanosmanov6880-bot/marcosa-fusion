## Ограничения до реального полного релиза

- Ни один из 20 репозиториев нельзя автоматически назвать подтверждённым независимым кино-доменом. Репозиторий `internet-v-humanity` содержит **только автономный playable preview**, не полный сервер v2.7.
- Собственные сайты и страницы на Contabo остаются недоступны через текущий SSH из-за неподтверждённого host key. Эту защиту не обходили.
- ZIP интеграции остаются локальными артефактами (не опубликованными автоматически). Для установки нужны тестовый сервер, владельческие доменные права, актуальные сборки, backup и откат.
- Без подтверждения прав на авторский контент и официальных адресов нельзя считать интеграцию запущенной, показы и продажи — полученными.
- При наличии фактической публикации, UI-релиз GitHub Pages подтверждается только после отдельного успешного запуска Actions.
