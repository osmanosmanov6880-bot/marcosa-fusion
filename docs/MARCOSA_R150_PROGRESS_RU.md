# MARCOSA R150 — журнал работ

База работы — R149 и PR #167. В локальном пилоте добавлены поиск сезонов по названию, описанию и автору, число доступных опубликованных выпусков и переход к первому выпуску. Доступ к результатам проверяется по приватности и блокировкам.

При аварийной остановке записи зритель может отписаться от сезона и удалить свои отметки. Проверка источника запроса сохраняется. В экспорт аккаунта добавлены собственные сезоны, эпизоды, настройки опросов, трудозатраты и собственные переходы к партнёрам. Сведения о других зрителях и их голоса не экспортируются.

Модель в `tools/finance/` рассчитывает три гипотетических сценария для трёх размеров аудитории. Числа и результаты являются входными предположениями, а не продажами. Описание входов и запуск находятся в `tools/finance/README.md`.

Для рабочих веток добавлен workflow без развёртывания и секретов. Он проверяет локальную лабораторию и финансовую модель. До включения workflow в базовую ветку GitHub может не создавать проверки на событие pull_request. Результат workflow следует проверять по конкретному run ID.

Проверки: `node --test server-lab/test/*.test.mjs`, `node --test tools/finance/model.test.mjs`, `node tools/finance/run.mjs`, `git diff --check`. Мобильный Chromium не открыл страницу из-за системного `socket() EPERM`; визуальная приёмка остаётся открытой. Финансовые транзакции, production Auth/Postgres/Storage и выплаты данным изменением не подключены.
