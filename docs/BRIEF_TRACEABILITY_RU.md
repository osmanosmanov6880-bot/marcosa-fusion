## Непереговорные инварианты

- Никаких подменов MARCOSA действующим Network OS прототипом.
- Нет изменений Supabase credentials, RLS, авторизации, реальных сообщений и существующих пользовательских данных.
- Нет авто-загрузки проектов на сервер, пока не проверены права, исходники, бэкапы и окружение.
- По наличию 43 слотов невозможно утверждать, что 43 сайта работают.
- По двум вариантам креатива нельзя говорить «A/B увеличил продажи», когда нет реальной экспериментальной выборки.
- Нет биллинга, денег, токенов или скидок по времени/репутации в текущем коде.

## Что код не может доказать без новых входных данных

Реальная аудитория, production доступность, доход, роли сотрудников, российская/европейская юрисдикция конкретных контрактов, права на изображения и музыку, Stripe, состояние Supabase Storage, безопасность E2EE и полноценные импортированные документы. Они остаются неизвестными, даже если скриншот или файл приложения выглядит убедительно.
