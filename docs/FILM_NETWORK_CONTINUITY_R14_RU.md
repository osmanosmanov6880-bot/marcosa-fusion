# MARCOSA R14 — сохранение и восстановление аудита кино-сети

**Область действия:** отдельная публичная статическая страница `film-network.html`, без изменений приватной MARCOSA, существующих доменов фильмов, Stripe, Supabase или Contabo. 24 октября 2026.

## Почему этот этап необходим

Предыдущая R13 позволяет импортировать CSV 43 доменов, отмечать проверки и выгружать JSON, но вся работа исчезает при закрытии вкладки. Нельзя надёжно проводить многодневный аудит вручную, если нужно каждый раз заполнять всё заново.

**R14 исправляет это двумя самостоятельными способами.**

1. **Сохранить локальный снимок:** кнопка «Сохранить текущую версию» записывает заполненные сайты, авторские самопроверки и замечания в IndexedDB браузера. Сохранение строго ручное, без отправки на сервер.
2. **Продолжить позднее:** после перезагрузки страницы список снимков остаётся. Кнопка «Восстановить» возвращает выбранную версию в редактор. При наличии текущих данных запрашивается подтверждение перед их заменой.
3. **До 12 независимых снимков:** история не перезаписывается. Переполненный архив отклоняет новые записи, пока пользователь вручную не удалит ненужный снимок. Проверка лимита выполняется в одной `readwrite`-транзакции IndexedDB.
4. **Восстановление по старому R13 JSON:** ранее сохранённый `marcosa-film-pilot-evidence/v1` можно открыть кнопкой «Открыть сохранённый JSON». Данные импортируются **в текущую вкладку**, а не автоматически записываются в хранилище.
5. **Строгая проверка входного JSON:** лимит 1 МиБ, точная форма полей, валидная дата ISO, 43 площадки, уникальные ID и домены. Все производные показатели пересчитываются. Любая попытка подменить `externally_verified:false`, `not_published`, `checks_completed`, `shortlist` или независимую проверку прав приводит к отказу импорта без изменения открытого аудита.
6. **Длинные заметки с переносами строк:** R13 теперь допускает обычные переводы строк в комментариях аудитора, сохраняя запрет других управляющих символов.

Новый модуль: `site/film-continuity.js`. Он использует работу R13 `site/film-network.js`, а не создаёт параллельный несовместимый формат. Индивидуальный проект и история не отправляются на сервер. Статусы прав на контент остаются **заявлениями владельца**, не являются юридической проверкой.

## Границы и приватность

- Это сохранение **только в браузере на текущем устройстве**, без облачной учётной записи или синхронизации.
- Снимки **не зашифрованы**, поэтому устройство должно быть доверенным. Не вписывайте пароли, приватные токены, документы с секретами.
- Очистка данных сайта, приватный режим или удаление браузера могут стереть IndexedDB. Для настоящей резервной копии скачивайте отдельный JSON из R13 и храните в безопасном месте.
- Сохранение никогда не выполняется автоматически и не опрашивает никакие кино-домены.
- Консоль GitHub содержит доступ к 20 репозиториям, но 43 домена не были обнаружены и **не приравниваются** к репозиториям.

## Приёмка

- `tests/film_continuity.test.cjs`: JSON roundtrip, сохранение переносов строк, поддельные права/публикация, неправильные домены, опасные поля, ограничения размера и формы снимка.
- `tools/r14_film_cdp.cjs`: настоящий Chrome с desktop 1440×900 и mobile 390×844, импорт CSV, заполнение 6/8, два неперезаписываемых снимка, перезагрузка, восстановление, отказ поддельному JSON, правильный импорт R13, лимит 12, освобождение места и повторное сохранение; снимки экрана.
- `tools/build_webroot.py`: строго **20** файлов публичной страницы, отсутствие SQL, ключей и персональных файлов в артефакте.
- Успех браузерных тестов GitHub Actions не равен подтверждению собственных 43 реальных сайтов или реальных пользователей.

## Следующий практический шаг

После получения настоящего CSV доменов проверить **три первых** сайта в браузере, лицензионное основание использования материалов, разветвления и точки установки CTA. Подтвердить результат независимым аудитом, затем подготовить PR в **исходных репозиториях именно этих сайтов** и проверить откат. Платежи/публичную рекламу не запускать до доказанной работы интеграции и соответствующих юридических проверок.
