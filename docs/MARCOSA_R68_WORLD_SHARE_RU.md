# MARCOSA R68 — настоящие страницы Worlds

`GET /w/:slug` возвращает HTML-страницу и актуальные метаданные OpenGraph из локальной SQLite. Новая постоянная ссылка используется кнопкой World; старые `/#world-*` остаются рабочими. Названия и описания экранируются, чужие блокировки дают 404, ссылка на изображение появляется только после действующего одобрения модератором.

**Лаборатория не индексируется:** заголовок `X-Robots-Tag: noindex, nofollow` и HTML meta robots. Публичное SEO требует production HTTPS, Auth/Storage, прав на контент и независимой юридической приёмки.

`server-lab/test/r68.world_pages.test.mjs` проверяет URL, HTML/XSS, блокировки и отзыв роли модератора. Chromium дополнительно проверяет загрузку `/w/slug` на 1440/390/360, OG, фокус и возврат в каталог. Не объявлять готовность без успешных CI точного SHA.
