# MARCOSA R12 — самостоятельная интерактивная история в одном HTML-файле

**Дата: 24 октября 2026.** Реализовано в публичном статическом конструкторе MARCOSA Creator. Выпуск допускается к публикации после успешных GitHub Actions / Chrome acceptance. Это **не** публикация автора на MARCOSA, не новая игра AAA и не платформа со сторонними аккаунтами.

## Реальное пользовательское действие

1. Открой Creator Engine и заполни название, краткое описание, первую сцену, обе вторые сцены и все четыре финала.
2. В новом блоке **«Создать свою мини-игру»** выбери тему: «Звёздная ночь», «Алый горизонт» или «Северное сияние».
3. Нажми «Проверить автономную историю»: настоящий скомпилированный HTML откроется в защищённом iframe прямо в редакторе. Текст не отправляется на сервер.
4. Подтверди право на содержание, маркировку рекламы и отсутствие приватных сведений.
5. Нажми «Скачать интерактивный HTML». Скачанный файл автономен: его можно открыть в Chrome/Edge/другом современном браузере **без интернета и серверов**.
6. Игрок проходит два решения: A или B, после каждого первого выбора отдельная следующая сцена с A/B, итог — один из четырёх оригинальных финалов. Есть возврат и рестарт, клавиши 1/2, стрелка влево и R.

Создание HTML **не включает аккаунты, рекламу, аналитику, платежи, автоматическое размещение на доменах или независимое одобрение прав**. Пользователь может самостоятельно переслать или разместить файл там, где ему разрешено.

## Технический контракт и безопасность

- Источник: только текущая редактируемая история, валидируемая строгой R8-функцией normalizeDraft; 2 ветки и 4 финала. **Архив IndexedDB, версии, пароли, ключи и другие проекты не включаются.**
- Встроенный контракт: marcosa-standalone-playable/v1. В HTML включаются только title, tagline, language, opening, branches[2], endings[4].
- Тексты сериализуются в Base64-кодированный UTF-8 JSON. Даже теги script и img, написанные внутри рукописи, не могут разорвать разметку HTML.
- При запуске игры данные попадают на экран исключительно через textContent, а не innerHTML.
- В HTML нет внешних изображений, скриптов, шрифтов или CSS-файлов. Три темы CSS встроены в **один локальный файл**.
- Вычисляется SHA-256 точного содержимого единственного inline JavaScript-плеера. CSP внутри HTML запрещает внешние ресурсы, сетевые подключения, объекты, формы и скрипты, кроме проверенного SHA-256. Содержимое истории остаётся данными, а не исполняемым JavaScript.
- Предпросмотр в редакторе запускается внутри iframe с sandbox=allow-scripts и referrerpolicy=no-referrer, без allow-same-origin. Плеер не получает доступ к хранилищу редактора.
- Генерация требует HTTPS или localhost для WebCrypto SHA-256. **Уже скачанный файл работает с file:// без WebCrypto и сервера.**
- Размер созданного HTML ограничен 180 КБ; исходные поля валидируются.
- Не создаётся ложный статус published, статус проверенных прав или обещание лицензии на чужой контент.

## Реальные проверки

- tests/standalone.test.cjs: четыре финала, разрешённые поля, CSP SHA-256, защита от инъекции разметки, допустимые темы и языки RU/EN/中文, безопасные имена файлов, обязательные галочки, отсутствие сетевых вызовов.
- tools/r12_offline_cdp.cjs: Chrome в двух размерах 1440×900 и 390×844 открывает файл с file://, проходит четыре пути, проверяет «Назад», «Рестарт», клавиатуру, XSS, отсутствие HTTP-запросов и горизонтальной прокрутки.
- tools/r5_capture_preview.py: скриншоты панели генерации HTML на компьютере и телефоне. CDP сохраняет также снимки автономной истории, реально запущенной с локального файла.
- tools/build_webroot.py: фиксированный список из 15 публичных файлов, SHA-256 manifest. Сторонний контент, SQL-проект и секреты не попадают в Pages.

## Границы и следующий шаг

R12 — ограниченная повествовательная 2D мини-игра, не движок уровня Unreal Engine и не площадка коммерческой публикации. Сам файл не обеспечивает проверку прав, платежи, облачное сохранение и статистику игроков.

Для дальнейшего развития: пользовательские тесты, расширенный граф сценария, доступность чтения скринридерами, затем — независимый серверный проект с авторизацией и модерацией.

**Contabo/SSH, Stripe, MARCOSA production и Supabase не изменяются.** Это расширение только публичного предпросмотра GitHub Pages.
