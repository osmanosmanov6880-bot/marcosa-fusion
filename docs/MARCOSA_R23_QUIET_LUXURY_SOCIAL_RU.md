# MARCOSA R23 — Quiet Luxury / Social First

## Решение по обратной связи
Пользователь отклонил футуристическую визуализацию. MARCOSA прежде всего воспринимается как **социальная среда для людей, идей и творчества**, а не космическая стратегия. Новый дизайн должен быть сдержанным, статусным, человеческим, хорошо читаемым.

**Это изменение настоящего GitHub Pages-проекта, а не генерация картинки.**

## Визуальная система
- Палитра: тёплый фарфор `#F3F0E9`, мягкая бумага `#FBF9F4`, графит `#252822`, шалфей `#63705C`, матовое шампанское `#B29A78`. Вместо неона — тонкие линии, спокойные поверхности и аккуратная глубина.
- Заголовки: редакционная типографика `Iowan Old Style / Baskerville / Palatino Linotype / Georgia` с крупным кеглем, идеальной высотой строк. Интерфейс: `Aptos / Segoe UI Variable / Segoe UI`, минимум 15–16px.
- Отказ от космического корабля, орбитальных лучей, завышенных теней, «светящихся кнопок» и микро-текста. Без внешних шрифтов, CDN, сторонних изображений.
- Характер: архитектурный журнальный люкс, больше воздуха, тактильность тёплого камня, керамики, кожи и бумаги без имитации рекламы модного дома.
- Логотип: спокойная марка MARCOSA, неизменная узнаваемая M, без голографических эффектов.
- Переходы: неброский fade 180–250ms с reduced-motion, без туннеля и вспышек.

## Продуктовые приоритеты
1. Home / MARCOSA как social-first-портал. Главный CTA — «Открыть ленту», затем «Создать заметку». Содержимое связано с **существующими** разделами и реальными исходниками.
2. Social Core — первая по иерархии вкладка. Сохраняем рабочие фильтры, поиск, локальные закладки и черновики; увеличиваем размеры элементов; по факту это **публичное превью**, а не работающая серверная соцсеть с реальными аккаунтами.
3. Cinema, Creator, Atlas — разные направления, но единая типографика и спокойный визуальный язык. Настоящие 6 кино-движков и механика их запуска не трогаются.
4. Никогда не показывать фиктивных пользователей, подписчиков, сообщения, лайки, транзакции или охваты.
5. Адаптивность: desktop 1440x900, mobile 390x844; дополнительно 360px. Кнопки touch 44px+, без горизонтального переполнения и без внешних запросов.
