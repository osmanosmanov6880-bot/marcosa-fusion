# MARCOSA R152 — пять инженерных блоков локальной лаборатории

База: PR #168, feature/marcosa-r150-growth-economics. Изменения выполняются для синтетических пользователей, отдельного Node/SQLite и GitHub Actions, без доступа к платёжным счетам.

1. **Сквозная авторская приёмка.** `tools/browser/author-journey-r152.mjs`: Chromium (1440 и 390): регистрация, вход, публикация, создание сезона, два выпуска, подписка, добровольная отметка, продолжение чтения и закрытие личного напоминания. Тест фотографирует конечную страницу.
2. **Защищённые тестовые начисления.** `ops/payment-contract/creator-earnings-r152.mjs`: неизменяемая ставка в basis points на один заказ; основание — проверенный синтетический R76 receipt. Суммы целые в минимальных единицах; нулевых или живых платежей в контуре нет.
3. **Двухэтапная сверка.** Контрольный SHA-256 по заказам, роль автора batch и отдельного аудитора, идемпотентность, отказ при изменении выплат из-за возврата либо спора R86. Сверка означает только внутренний тест, **не перевод денег**.
4. **Доказательство восстановления.** `ops/test/r152.disaster-recovery.test.mjs`: автор, сезон, подписка и отметки, тестовые финансовые записи, backup/restore в новый путь, повтор безопасных операций, отказ при испорченном manifest, проверка foreign keys.
5. **Управляемый staging NO_GO.** `ops/staging/r152-readiness.mjs`: строгий контракт проверок, main SHA, независимого SSH host pin, HTTPS readback, reviewer и digest. По умолчанию NO_GO; даже позитивный самодекларированный пример только готов к *отдельной* ревизии, не к deploy. CI не содержит секретов и действий на VPS.

## Проверка

```sh
node --test ops/payment-contract/creator-earnings-r152.test.mjs
node --test ops/test/r152.disaster-recovery.test.mjs
node --test ops/staging/r152-readiness.test.mjs
node ops/staging/r152-readiness.mjs
node tools/browser/author-journey-r152.mjs
```

Объективный статус подтверждается только итогом соответствующих GitHub Actions. Настоящие выплаты авторам, production Auth/Postgres, права на контент, лицензии, коммерческое развёртывание и внешнее HTTPS доказательство здесь **не выполняются**.
