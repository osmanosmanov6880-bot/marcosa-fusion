# MARCOSA R65 — жалобы на уже опубликованные изображения, независимое скрытие и право апелляции

**Новый реальный функционал локальной социальной платформы**. Код работает через SQLite + loopback HTTP API + кнопки в настоящем интерфейсе. Не является юридической формой, мировым production или автоматическим распознаванием нарушений.

## Пользовательский сценарий

1. Владелец загружает PNG, исходная независимая проверка одобряет обложку. Мир содержит публичное изображение.
2. Другой **авторизованный** пользователь открывает World; если это не его мир, появляется форма жалобы на обложку. Возможные основания: авторские права, приватность, оскорбительные материалы, выдача себя за другого, иное. Необязательных секретных пользовательских действий нет: объяснение от 12 до 500 символов обязательно.
3. HTTP `POST /api/worlds/:slug/cover/report` сохраняет жалобу приватно с `SHA-256` *конкретного текущего изображения*, без прямой публикации текста жалобы или автоматического скрытия PNG. Защищены Origin, сессия, чужой World, ограничения частоты и повторная жалоба на те же байты.
4. Только независимый модератор (не владелец, не жалобщик, не исходный одобривший модератор) видит приватную очередь `GET /api/mod/cover-reports`. Картинка и имена жалобщиков не передаются в JSON очереди.
5. `POST /api/mod/cover-reports/:id/resolve`: `upheld` скрывает PNG атомарно с решением, дополняет журнал модерации и закрывает другие обращения по этому образцу. `dismissed` сохраняет публичную обложку. Повторные решения невозможны.
6. После `upheld` владелец видит материал как `rejected` и получает **существующее** право независимой апелляции R59; обращение не публикует контент автоматически.
7. Новый PNG отзывает все открытые жалобы на предыдущий файл; предыдущий digest не может скрыть новый материал. Удаление аккаунта жалобщика каскадно удаляет его обращения; пользовательский экспорт включает только собственную историю жалоб.

## Реальные API-маршруты

- `POST /api/worlds/:slug/cover/report` — новая жалоба.
- `GET /api/me/cover-reports` — личная история текущего пользователя.
- `GET /api/mod/cover-reports` — изолированная очередь независимого модератора.
- `POST /api/mod/cover-reports/:id/resolve` — одноразовое независимое решение.
- Существующий `GET /api/worlds/:slug/cover` начинает возвращать 404 сразу после подтверждённого скрытия.

## Тесты

`node --test server-lab/test/r65.cover_takedown_reports.test.mjs` исполняет реальный Node/SQLite HTTP сервер; регистрирует отдельного владельца, жалобщика и двух модераторов; загружает реальные пиксели PNG, проверяет приватность, CSRF, права, digest replay, атомарное подтверждённое скрытие, независимость и журнал; затем проверяет новый PNG, dismiss, replacement и каскадное удаление аккаунта. Выполнение включено в обязательную CI проверку.

**Не закрывает мировые юридические требования:** нельзя обещать, что лабораторная форма заменяет лицензионные соглашения, официальное правообладательское уведомление, сроки юридического ответа, исполнение правового удаления или внешнюю 24×7 модерацию. До production требуются законные процедуры и независимая приёмка согласно Issue #55.
