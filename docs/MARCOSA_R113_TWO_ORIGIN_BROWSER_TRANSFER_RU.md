# MARCOSA R113 — реальная проверка переноса локальных данных между доменами

## Цель
R110 добавил пользователю работающий экспорт/импорт **закладок и короткой приватной заметки** в `Social Core`, но прежний браузерный QA выполнялся в рамках одного HTTP origin. R113 доказывает, что перенос требует явного действия пользователя и работает между **двумя разными origin**.

## Реализация
- `tools/r113_two_origin_cdp.cjs` создаёт два разных локальных сервера на `127.0.0.1` с независимыми портами. Разные порты браузер считает разными origin, даже при одном доменном имени.
- Используется реальный headless Chromium с **временным профилем**, который удаляется в конце. Никаких посещений `marcosa.club`, серверных паролей, пользовательских данных, подключений Supabase или сетевых запросов на внешние сайты.
- На origin A реальный интерфейс создаёт закладку и черновик; браузер выполняет экспорт, после чего проверяется фактический JSON-архив.
- На origin B изначально нет данных A; импорт с выбором файла восстанавливает закладку и черновик. Перезагрузка страницы подтверждает устойчивость хранения.
- Если на B уже есть собственная другая заметка, повторный импорт **не перезаписывает её** и объединяет закладки без дубликатов.
- Повреждённый файл не меняет существующую коллекцию.
- Возврат на origin A подтверждает неизменность исходных данных; тест блокирует неожиданные внешние HTTP-запросы и ошибки JavaScript.
- Тест запускается в обязательном `.github/workflows/marcosa-public-pages.yml` **после сборки**, до публикации и внешнего SHA-256 HTTPS-readback, а также проверяется в быстром R113 CI.

## Границы
Этот перенос применяется к закладкам и короткой заметке в Social Core. Для многостраничного журнала R27, проекта Creator и зашифрованных архивов существуют отдельные инструменты; R113 **не утверждает**, что переносит их автоматически или синхронизирует аккаунты.

Данные в JSON-архиве **не зашифрованы**. Пользователь должен скачать и перенести его самостоятельно, не помещая туда пароли, токены или другие секреты.

Никакой тест двух origin не означает готовности `preview.marcosa.club`: по последнему R109 DNS/TLS этот поддомен ещё не готов. Рабочий независимый предпросмотр: https://osmanosmanov6880-bot.github.io/marcosa-fusion/.

## Условия готовности
R113 засчитывается полностью только когда GitHub Actions подтвердит `R113_TWO_ORIGIN_REAL_CHROME=PASS`, затем публичный Pages `publish` и внешний `PUBLIC_GITHUB_PAGES_READBACK=PASS` для **того же** коммита. Результаты тестов нельзя подменять отметкой об успешной сборке.
