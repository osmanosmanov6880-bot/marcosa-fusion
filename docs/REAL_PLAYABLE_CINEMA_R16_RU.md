# MARCOSA R16 — настоящий игровой пролог в публичной киносети

**Дата: 24 октября 2026.** Одно из трёх проверенных кино-репозиториев содержит автономный пролог, который может запускаться в публичной сборке MARCOSA без изменения истории. Для остальных двух проверенный код есть, но их полноценные ассеты и публичные маршруты отдельно не подтверждены.

## Реально работающий пользовательский сценарий

1. С главной MARCOSA или Source Atlas перейти по ссылке «ИГРАТЬ В КИНО».
2. Открыть кино-зал cinema-pilot.html и нажать «ЗАПУСТИТЬ ИСТОРИЮ». Исходник запускается только после действия.
3. Играть в подлинный THE INTERNET v. HUMANITY: пролог, архив, улика, цифровой суд, два положения вердикта и два независимых финала. Можно нажать «НАЧАТЬ ЗАНОВО».
4. Для просмотра в отдельной вкладке выбрать «ОТКРЫТЬ ОТДЕЛЬНО». Это автономная страница, а не серверная игра с аккаунтами.
5. После состояний end_human / end_algorithm появляется отдельная добровольная ссылка в MARCOSA, без передачи решений игрока и личных данных. Автоматического перехода нет.
6. Карточки PROTOCOL ZERO и ADVERSE JUDGE открывают настоящие исходники GitHub. Кнопка «Играть» там не показывается, пока у них нет отдельно проверенных публичных маршрутов.

## Изоляция от основного сайта

- Встроенный проигрыватель работает в sandbox с allow-scripts, allow-popups и allow-popups-to-escape-sandbox, но **без allow-same-origin и allow-top-navigation**. Пролог не может читать данные MARCOSA.
- Встроенная игра запускается только по кнопке. При отдельном открытии исходный фильм может сохранять историю в собственном localStorage, но не отправляет её по сети. В sandbox localStorage блокируется, и исходный код безопасно обрабатывает эту ситуацию.
- Не используются внешние API, отслеживание, рекламные пиксели, платёжные сервисы или автоматическая переадресация.
- Проверка в Chrome: desktop 1440×900 и mobile 390×844; действительные click-пути по обеим концовкам, ветке с уликой, запуск/перезапуск, горизонтальная прокрутка, скриншоты, отсутствие внешних HTTP-запросов.
- GitHub Pages — публичный прототип. Никаких изменений действующего Contabo, Supabase, Stripe и чужих доменов.

## Приёмка

- tests/cinema_pilot.test.cjs: источник, безопасность, маршруты, доступные UI-контролы.
- tools/r16_cinema_cdp.cjs: реальный Chrome в двух размерах, обе финальные сцены и путь с уликой.
- tools/build_webroot.py: 27 строго разрешённых публичных файлов; приватные архивы и секреты в сборку не попадают.

**Честное ограничение:** это полноценный запускаемый исходный *пролог*, а не завершённая AAA-игра. Из 43 обсуждавшихся доменов пока нет подтверждённого списка с исходниками/правами/развёртыванием. Остальные две киноигры проходят отдельный этап упаковки и браузерной QA.
