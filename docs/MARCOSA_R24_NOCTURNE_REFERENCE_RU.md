# MARCOSA R24 — NOCTURNE / Premium Social Worlds

## Решение владельца
Строгий визуальный ориентир — предоставленный **9-панельный тёмный референс** (Network OS + четыре мира + мобильное приложение), но **с меньшей долей футуристики**. Предыдущая белая версия R23 отклонена. Не генерировать картинки и не выпускать статический лендинг вместо существующего приложения.

## Design tokens
- Общая основа: полуночный индиго `#070c17`, насыщенный синий `#101c2d`, карточки `#141f30`.
- Бренд: матовое шампанское `#d7bd93` и латунь `#b99d70` — не сияющее золото и не neon.
- Social Core: сливово-бордовая редакционная галерея `#261822` с глубоким тёмно-синим фоном, крупной типографикой и живой рабочей лентой.
- Cinema: бархатный винный `#21151d`; Studio: холодная синяя сталь `#132337`; Source Atlas: благородный морской `#12282b`; Story Lab: приглушённый аметист; Film Network: графит.
- Типографика: выразительная антиква Georgia / Palatino / Baskerville для заголовков; Segoe UI / Aptos для интерфейсов; текст 16–20px, крупные кнопки 44px+, никаких микроподписей 7–9px.
- Уникальный золотой логотип М с тонкой сдержанной орбитой. Без анимированных звездолётов, громадных планет, «голограмм» и кислотного свечения.
- Фон: реальные и уже проверенные визуальные материалы из **собственных кино-движков**, с приглушённым цветом. Никаких внешних изображений, шрифтов, аналитики и CDN.

## Требования к реальному продукту
1. `index.html`: восстановить **функциональную** трёхколоночную схему утверждённого референса: слева понятное меню, центр — широкая архитектурная фотосцена с заголовком «A network of worlds», справа четыре настоящих направления.
2. На главной первым переходом должна быть **социальная лента**, затем кино, студия и каталог. Не показывать фиктивные 50K, миллионы пользователей, лайки, профили и аккаунты.
3. Под центральной сценой — четыре различающиеся карточки и блок реальных возможностей сообщества: просмотр ленты, личные черновики и сохранённые материалы. Каждый CTA ведёт на работающий маршрут.
4. `social.html` остаётся **работающей локальной social-preview** (поиск, фильтры, закладки, черновики). Изменить визуальную систему без поломки механики. Поддержать ссылку сразу на фильтр «Сохранённое» через `?view=saved`.
5. `cinema-pilot.html`, `creator.html`, `source-hub.html`, `stories.html` и `film-network.html`: каждый мир узнаваемо свой, но цвета/логотип/типографика связаны.
6. Дизайн без горизонтального скролла на 360/390px. Глобальные переходы, клавиатурная навигация и reduced-motion работают, загрузка отражает реальную навигацию.
7. R22/R23 исходники для отката остаются в Git; R24 становится видимой темой. Никаких подмен готового приложения статической картинкой.

## Definition of Done
- Визуальные тесты Chromium на 1440x900, 390x844 и 360x740: тёмная главная, видимая широкая сцена, работающие направления и поиск; на Social — тёмная лента, сохранение, черновик, no overflow, no external requests.
- Узловые Node/Python тесты, SHA исходных WebP, 6 настоящих движков сохранены.
- Pull request + визуальные PNG-артефакты; слияние в main только при зелёном GitHub Actions, затем проверенный Pages deploy.
- GitHub Pages остаётся публичным прототипом. Аккаунты/общедоступные посты/личные сообщения на сервере не подключены.
