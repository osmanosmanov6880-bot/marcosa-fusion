# MARCOSA R114 — единая доказательная приёмка GitHub Pages + Contabo STAGING

## Суть
До R114 в GitHub существовали раздельные показатели двух каналов выпуска: GitHub Pages и изолированный Contabo SSH STAGING. Успех любого из них по отдельности **не доказывает**, что оба получили одну и ту же проверенную версию.

R114 создаёт read-only проверку для **одного конкретного полного Git SHA**.

## Новый конвейер
- `ops/release_evidence_r114.mjs` подключается **только** к REST API репозитория `osmanosmanov6880-bot/marcosa-fusion` с read-only GitHub Actions токеном.
- Независимо читает фактический `main` и два Workflow-run: `MARCOSA | Publish public Network OS preview` и `MARCOSA | Build, test and deploy STAGING`.
- Для GitHub Pages дополнительно требует успех трёх отдельных jobs: `verify-and-build`, `publish`, `verify-public-bytes`. Это доказывает не просто сборку, а полную публикацию с внешним HTTPS-readback всех манифестных файлов.
- Для Contabo требует jobs `build` и `deploy_ssh_filesystem`: сборка+контроль перед копированием и доставка проверенного STAGING на VPS.
- Если каналы отработали на разных Git SHA или один job отсутствует, **PASS не выдаётся**. Если `main` уже указывает на другой SHA, отчёт получает `SUPERSEDED`.
- `tests/release_evidence_r114.test.mjs` проверяет успешный двухканальный релиз, незаконченные действия, пропущенные jobs, отмену, ошибку, различие коммитов, неверную ветку и устаревший релиз.
- `.github/workflows/marcosa-r114-release-evidence.yml` автоматически стартует **после завершения** каждого из двух release workflows. Отсутствие второго канала отражается статусом `PENDING`, а не фантазийным успешным выпуском. Сводка и JSON-артефакт доступны через GitHub Actions.

## Статусы

| Статус | Что означает |
|---|---|
| PASS | Оба канала завершили обязательные jobs успешно **для текущего полного SHA main** |
| PENDING | Какой-то канал ещё не запущен / не завершён / доказательство недостаточно |
| FAIL | Публичный HTTPS-readback, SSH STAGING или иной обязательный job завершился неуспешно |
| SUPERSEDED | Рассматриваемый commit больше не является текущим `main`; не выдавать его за последний |

## Границы доказательств
**R114 не выполняет деплой.** Он читает GitHub API, пишет собственную сводку и не может изменять Nginx, DNS, Supabase, аккаунты, платежи, исходный `/opt/marcosa/current` или другой код на сервере.

**PASS относится только к публичному статическому предпросмотру GitHub Pages и закрытому STAGING.** Он не является доказательством полноценной многопользовательской социальной платформы и **не разрешает** переключать `marcosa.club` на статический архив.

Действующий публичный предпросмотр: https://osmanosmanov6880-bot.github.io/marcosa-fusion/.

До использования `preview.marcosa.club` необходимы рабочие DNS/TLS и проверка cookie-изоляции, а перед заменой старого приложения — аудит Auth, Supabase/RLS и отдельно одобренный root-controlled план отката.
