# MARCOSA R85 — реально проверенный входной контроль PNG, локальная лаборатория

**Только Node 22 + SQLite.** Этот блок не создаёт Supabase Bucket,
не загружает материалы в облако и **не является** доказательством
полноценного антивируса / CDN / private Storage.

## Что реализовано

- Детерминированный корпус корректных PNG: RGB и RGBA, с и без
  дополнительного `tEXt` метаданного; проверяет удаление описаний и
  абсолютную идемпотентность нормализации.
- Явно отбрасываются: неверная сигнатура, оборванные куски,
  CRC-повреждение, данные после IEND, неподдерживаемый цветовой тип,
  некорректные filter байты, огромные размеры / pixel bombs,
  расширенный zlib, дублированный IHDR, неизвестный critical chunk,
  APNG acTL/fcTL/fdAT и превышающий лимит файл.
- 1800 повторяемых случайных битовых мутаций входных файлов проходят
  через **реальный** `sanitizePngCover`: любой принятый файл должен
  быть нормализованным, не превышать предел пикселей/байт, не
  содержать входных тектовых метаданных и повторно нормально
  обрабатываться. Отклонение должно выдавать `INVALID_PNG_COVER`.
  Это fuzz-подобные испытания, не исчерпывающий security fuzzing.
- Настоящий HTTP/SQLite сценарий создаёт пользователя через
  пригласительный код и пароль, проверяет cookie-сессию,
  отправляет повреждённые PNG с заявлением о правах, убеждается
  в HTTP 422 **без записи в БД**, затем загружает валидный PNG с
  метаданными, проверяет приватный `pending`, нормализованный
  SHA-256 и историю прав. Последующие неудачные загрузки не могут
  перезаписать сохранённый PNG или изменить историю прав.
- Приватный оригинал видит только действительный владелец после
  аутентификации, а публичная выдача до независимого одобрения
  возвращает HTTP 404. Проверяются FK.

## Как повторить

```bash
node --test server-lab/test/r85.adversarial_png_security.test.mjs
```

Этот тест включён в общий workflow социальной лаборатории.
Перед слиянием обязательны актуальный green социального сервера,
Chromium, World Builder, 12-контурная изоляция и нагрузочный read-test.

## Границы

Никакая проверка содержимого PNG не доказывает автоматически
законность прав или отсутствие любых эксплойтов. В production
потребуются AV/сканер политики, OS-sandbox с ограничением
ресурсов CPU/RAM, независимая модерация, подписанный short-lived
Storage/CDN доступ, блокировка кэша удалённых объектов,
ключи KMS, expiry/revocation и аварийный выключатель на всех
origin-узлах. Это зависит от действительного, явно разрешённого
Supabase/Storage-проекта, которого пока не видно в подключении.

Следовательно, R85 пока **реализован как отдельная группа негативных
тестов входа**, а **вся мировая облачная медиацепочка R85 остаётся
незавершённой**.
