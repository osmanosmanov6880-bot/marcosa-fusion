# MARCOSA R22 — обязательный визуальный бриф / IMPLEMENTATION CONTRACT

**Дата:** 2026-10-24
**Референс:** второе приложенное изображение пользователя «Премиальная UI-система MARCOSA в стиле космоса(1).png» (коллаж с 9 секциями: Brand Identity, Network OS, Social Core, Cinema, Creator Studio, Source Atlas, Transitions, Loading, Mobile Ecosystem).
**Требование:** НЕ генерировать новые изображения вместо работы. Изменять настоящий проект `osmanosmanov6880-bot/marcosa-fusion`, сохранять игровые движки, проверять сборку в Chrome и публиковать только после зелёного CI.

## Неприкосновенные правила

1. Один бренд во всех приложениях: объёмная золотая M с фирменной орбитой, разреженный MARCOSA, ночное звёздное небо, металлические поверхности, сочные световые акценты.
2. Разные миры — разные цвета/образы: Network OS — золотой + космос/мегаполис; Social Core — пурпур/красная космогония; Cinema — красная кинематографическая драма; Creator — индиго/голубой/монтажная студия; Source Atlas — бирюзовый/цифровой глобус. Story Lab и Film Network наследуют бренд, но имеют отдельные акценты.
3. Настоящие изображения высокого разрешения, не дешёвые CSS-кружочки в качестве основного фона. Переиспользовать **оригинальные принадлежащие проекту WebP-кадры** из уже зафиксированных исходных автономных кино-движков OpsPilot/IntentGraph; не подтягивать картинки с внешних сайтов и не заявлять авторство чужих работ. WebP извлекать на этапе сборки из их собственных data URI, снабдить SHA256 манифестом.
4. Публичный Gateway: полноэкранная панель-приложение (не плакат) с живыми ссылками/кнопками, боковой навигацией, контентной зоной, космическим мегаполисом, акцентным заголовком «A network of worlds.», блоком актуальных миров и проверенными метриками (не выдумывать людей, охваты, фолловеров и доход).
5. Social Core: фотореалистичная сцена города и сообщества, **сохранить** уже работающие фильтр, поиск, закладки и локальные черновики; нет реальных аккаунтов и публикаций, пока не подключён сервер.
6. Cinema: кадр/постер без фотографической заглушки, настоящий 6-фильмовой плеер (sandbox и добровольный запуск), мобильная адаптация.
7. Creator: кинематографический фон и рамка инструментария с существующим редактором; не имитировать несуществующий видеомонтаж.
8. Atlas: земной шар / голографический вид на фоне; фактический каталог исходников, никакой фальшивой статистики.
9. Переходы: светящаяся орбита и логотип, состояния меняются при **реальном переходе**; не показывать ложные проценты, не блокировать клавиатуру, `prefers-reduced-motion` отключает анимацию.
10. Мобильная версия: 390×844 и 360×740, без горизонтального скролла, удобные сенсорные кнопки и изображения без внешних запросов.
11. Старый Network OS, исходные игры и скрипты остаются в репозитории; не удалять рабочие формы и IDs, от которых зависят тесты и пользователи.
12. Важно: `github.io/marcosa-fusion` — **публичный прототип**, НЕ боевой сервер `marcosa.club`. Не публиковать никому логины, пользовательские данные, приватные ZIP, секреты, платежные функции.
