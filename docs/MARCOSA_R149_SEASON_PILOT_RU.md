# MARCOSA R149. Журнал реализации и инструкция пилота

База — R148, PR #166. Среда — существующая лаборатория Node и SQLite. Все персонажи, названия и рекламные предложения для пилота вводятся автором. Тестовые записи создаются только во временных базах.

## Что изменено

| Модуль | Действия участников | Где реализовано |
|---|---|---|
| Сезон | Автор выбирает свой мир, задаёт адрес, дату следующего выпуска и связывает опубликованные записи с упорядоченными эпизодами. Читатель открывает страницу без регистрации, если разрешает видимость. | server-lab/series.mjs |
| Развилка | Автор задаёт два варианта и срок. Участник может изменить или снять голос до закрытия. Автор связывает зафиксированный итог с более поздним эпизодом. | server-lab/votes.mjs |
| Подписки | Новая публикация создаёт внутреннее напоминание подписчикам. Повтор запроса не дублирует выпуск. Отписка удаляет напоминания. | server-lab/series-subscriptions.mjs |
| Отчёт автора | Зритель сам отмечает выпуск и может удалить свои отметки. Автор видит число отметившихся и записывает минуты производства. | server-lab/series-metrics.mjs |
| Партнёр | Автор прикрепляет прошедшее согласование предложение своего мира. Переход добровольный. Партнёр отдельно указывает подтверждённые и отменённые результаты. | server-lab/series-sponsor.mjs |

Семидневный возврат считается по зрителям первого выпуска, для которых прошло семь дней. В числителе — те, кто позже отметил второй выпуск в пределах этих семи дней. При пустом знаменателе доля отсутствует. Добровольные отметки измеряют только участвующую группу. Сумма подтверждений партнёра основана на введённых им кодах операций. Платежи, прирост продаж и реальная выручка этими числами не подтверждаются.

## Как повторить локально

Используйте Node с поддержкой node:sqlite, например проверенную версию 24.22.1. Из корня репозитория запустите следующую команду в Bash. Код приглашения задайте для этой локальной сессии.

```sh
read -rs -p 'Локальный код приглашения (от 12 символов): ' MARCOSA_INVITE_CODE
export MARCOSA_INVITE_CODE
node server-lab/server.mjs
```

1. Откройте http://127.0.0.1:8787/ и зарегистрируйте автора. В его мире опубликуйте две записи. Для зрителя используйте отдельную сессию браузера.
2. Через «Авторские сезоны» создайте сезон и добавьте первую запись. Откройте сезон зрителем, подпишитесь и отметьте прочитанный выпуск.
3. Автором создайте голосование с будущим сроком, зрителем выберите вариант. Добавьте второй эпизод. Проверьте напоминание зрителя. После закрытия опроса свяжите итог со вторым эпизодом.
4. Сравните отчёт автора до и после добровольной отметки зрителя. Для проверки расчёта с истёкшими семью днями используйте автоматический тест с управляемым временем.
5. Для рекламного сценария требуется предложение для данного мира, принятое автором и одобренное независимым модератором. Воспроизводимый тест создаёт эти роли в отдельной базе. Участники могут отменить размещение.

По умолчанию база в памяти очищается после остановки процесса. Для сохранения пилота задайте MARCOSA_DB_PATH с путём к отдельному локальному файлу. Для возврата к R148 используйте предыдущую ветку с её отдельной копией базы.

## Проверка

```sh
node --test server-lab/test/*.test.mjs
git diff --check
```

Локальный пилот не проверяет production Auth/PostgreSQL/Storage, внешнюю доставку уведомлений, права на конкретные материалы или платёжный спрос.

## Исправления существующих сценариев

Загрузка реакций разбивается на пакеты с учётом числа и длины ID. Изменение реакции и сохранения синхронизирует копии карточки. Устаревший ответ навигации не перезаписывает открытый мир. Закрытый профиль фильтруется в ленте, поиске, сохранённых и комментариях наравне с прямой ссылкой.

## Ограничения приёмки

HTTP/SQLite и исполняемые проверки клиентской логики выполняются локально. Попытка запуска Chromium остановилась до создания страницы из-за ограничения системных сокетов. Визуальная приёмка на телефоне остаётся открытой.
