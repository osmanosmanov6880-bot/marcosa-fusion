# MARCOSA R71 — настоящая смена языка RU / EN (первый пользовательский блок)

**Статус:** реальный интерактивный UI в локальном Node/SQLite приложении. Не полный международный перевод и не production.

## Что реально работает

- В шапке доступен переключатель `Русский / English (beta)` на компьютере и телефоне, с клавиатурным фокусом и доступной меткой.
- Клиентский модуль `/i18n.js` содержит 201 вручную подготовленную RU/EN запись для публичной обложки, регистрации и входа, каталога, фильтров тем, страниц World, обращения по изображению, публикации, ленты, принципов доверия и тестовых рекламных заявок.
- Текущая локаль хранится в браузере через `localStorage` без отправки на сервер; поддерживается `?lang=en` как входной выбор. При закрытом/недоступном storage интерфейс всё равно позволяет переключать язык.
- `<html lang>`, текстовые надписи, `placeholder`, `aria-label` и `alt` меняются непосредственно, без `innerHTML`. Переключатель сохраняет весь DOM формы и введённые поля; режим уменьшения анимации не нарушается.
- Динамические **системные** кнопки «Открыть World», фильтры тем, статус готовности сервера и подпись «Гость» переводятся без потери исходных значений `slug`, ID и `value`.
- Никаких внешних переводчиков, сетевых обращений к AI или автоперевода пользовательского контента.

## Безопасность приватных данных

Модуль снимает снимок только доверенного статического HTML **до загрузки** динамических аккаунтов/миров/постов `app.js`; изменения применяются только к сохранённым текстовым узлам и их атрибутам. Поэтому заголовок World «Войти», пользовательское описание «Пароль», текст публикации «Твой доступ» остаются **буквально неизменными**, хотя те же строки как системные надписи переводятся. Это важнее автоматического перевода без разрешения автора.

Серверный `GET /w/:slug` сохраняет название и описание пользователя и `noindex` в метатегах: перевода пользовательского содержания или публикации новых SEO-страниц нет.

## Независимая приёмка

`node server-lab/test/r71.bilingual_browser_cdp.mjs` запускает настоящий Node/SQLite сервер, регистрирует пользователя, вставляет в БД тестовые World и пост с фразами из словаря и запускает Chrome на **1440, 390 и 360 px**. Проверяются RU → EN, хранение локали, повторная загрузка, сохранение текста пользователя, английские системные кнопки и фильтры, SSR-страница `/w/slug`, возврат RU, отсутствие внешних запросов, отсутствие JS-исключений и горизонтальной прокрутки. Шесть реальных скриншотов собираются в `qa-r71/`.

## Что ещё открыто

Это **English beta** публичной оболочки, а не полный перевод интерфейса. Динамические сообщения модерации, пользовательские сценарии личного кабинета, юридические тексты, уведомления, ошибки API и серверные письма требуют отдельной локализации и независимой проверки носителями языка. Отдельные английские публичные SEO-страницы потребуют настоящего production/HTTPS, авторских прав, юридической приёмки и go/no-go Issue #55. Полный локальный и мировой выпуск этим PR не разрешён.

### Проверка полноты статического интерфейса

`node --test server-lab/test/r71.locale_dictionary.test.mjs` независимо проверяет 201 ключ, отсутствие дубликатов/пустых значений, отсутствие сетевых переводчиков и полное покрытие исходных русских надписей статического HTML. Исключения только название вкладки (локализуется отдельно) и слово «Русский» как родное имя варианта языка. Динамические тексты API/ошибок ещё требуют второго этапа — не называть текущую версию полным переводом.
