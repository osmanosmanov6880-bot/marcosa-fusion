# MARCOSA R45 — крупный блок подготовки закрытой беты

## Выполненная разработка (в этой ветке до CI)

**Внешний контур:** R45 не меняет GitHub Pages, чужие сервера или реальные Supabase/Auth. Проект по-прежнему `server-lab/` (Node 22, локальная SQLite, localhost/Host/Origin guard).

**Безопасность выдачи доступа:** модератор выдаёт криптографически случайные 24-байтные токены (hex); хранилище содержит SHA-256, TTL 1–168 часов и ссылки на оператора/участника. Код возвращается только однократно при выдаче; список без секретов, персональный, ограниченный. Регистрация в одной транзакции одновременно создаёт аккаунт/World и погашает код. Одновременные запросы не могут списать один код дважды. Варианты `legacy`, `single-use`, `closed`; для закрытой беты нужен `single-use`.

**Автономный оператор:** CLI повышает ровно первого локального модератора только на заранее существующей приватной исправной SQLite базе, требует явный флаг, отзывает сессии. Никаких бэкдоров выдачи роли из `raw_user_meta_data` или фронтенда.

**Онбординг:** пять настоящих прогресс-событий из постов, подписок, комментариев, описания мира и сохранений; нет искусственных рекламных метрик. Доступ — только собственному аккаунту.

**UX:** новые элементы в существующем спокойном премиальном интерфейсе; вместо всплывающих рекламных баннеров — встроенный чек-лист; модераторское управление отдельно от пользователя, мобильные элементы доступны пальцем.

## Приёмка с фактами

- [ ] Node/SQLite API тест R45: два этапа запуска с настоящей дисковой базой, single-use, конкурентное списание и rollback.
- [ ] Полная обратная совместимость R28–R42, включая смену пароля, блокировки, сохранения и обработку рекламного согласия.
- [ ] Настоящий Chromium: desktop 1440, phone 390/360, реальные формы и работа без внешних запросов; секрет отсутствует в QA-скриншотах.
- [ ] GitHub Actions на точном SHA успешен; слияние с `main`.
- [ ] Регистрация MARCOSA в интернете остаётся закрыта, пока не выполнен release gate #55.

## Следующие крупные блоки до релиза

1. **W1 — Auth и STAGING:** проверенный владельцем SSH host-key, изолированный HTTPS, подключённый Supabase проект, настоящие JWT, восстановление резервной копии.
2. **W2 — безопасное хранение/права:** проверенные миграции R30/R37/R41/R43 + новая схема приглашений, публичные медиа только после контент-аудита; Storage policies, quotas, upload validation.
3. **W3 — социальная ценность:** качественные обсуждения, модерирование, сохранения, рекомендательная выдача с объяснимым сигналом (без скрытой слежки), accessibility и мобильные измерения.
4. **W4 — B2B/Ads:** 10 интервью с рекламодателями, реальное согласие на кампанию, верифицируемая статистика доставки, платёжный провайдер и прозрачный ledger; не включать оплату раньше аудита.
5. **W5 — закрытая бета и go/no-go:** 10 независимых тестировщиков, затем приглашённая когорта до 100; считать фактические активации/полезные ответы/D7 и D30 по подтверждённым когортам, правовые основания обработки. Решение масштабировать только на доказательствах.

**Нельзя объявлять «мировой релиз завершён» по номеру R, числу тестов или косметике.** Настоящий worldwide release требует юридически/операционно подтверждённой безопасности, платежей, прав пользователей, отказоустойчивости и спроса.
